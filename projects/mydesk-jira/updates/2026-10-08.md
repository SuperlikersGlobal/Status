# MyDesk + Jira — Actualización 08/10/2026

## Resumen

Se decidió reutilizar el gestor de tareas que ya existe en MyDesk para sustituir gradualmente Jira. No se desarrollará un sistema paralelo ni se usará GitHub Issues como almacenamiento operativo.

## Avances de esta etapa

1. Se estudiaron las funcionalidades existentes del MyDesk para aprovechar tareas, tableros, responsables, comentarios, historial y proyectos.
2. Se implementó y validó localmente un flujo en el que el trabajo puede pasar por revisión y aceptación antes de finalizar.
3. Se corrigió el comportamiento de entrada de incidencias importadas, todavía sólo en el desarrollo local.
4. Se preparó una clasificación previa de la jerarquía de Jira para evitar perder las relaciones entre elementos al migrar.
5. El clasificador se probó con un conjunto real de trabajo abierto leído sin modificaciones. La conciliación de identificadores resultó correcta.

## Pendientes confirmados

- Resolver tres relaciones jerárquicas excepcionales antes de aprobar el modelo de importación.
- Determinar cómo conservar el trabajo registrado en elementos padre que pasarían a agrupar tareas.
- Revalidar únicamente lo que resulte afectado por esas decisiones.
- Completar la preparación de la importación y validar los responsables antes de un piloto.
