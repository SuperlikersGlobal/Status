# MyDesk + Jira

**Responsable:** Bruno  
**Estado:** En progreso — piloto validado localmente, publicación pendiente.  
**Última actualización:** 2026-10-15

## Objetivo

Que los equipos de SuperLikers organicen y terminen su trabajo cotidiano en MyDesk, sin depender de Jira para las tareas nuevas.

## Qué ya tenemos

- Tareas, responsables, estados, prioridades y fechas.
- Tableros, listas, proyectos, historias y sprints.
- Comentarios, seguimiento, revisión y aceptación de entregas.
- Una versión piloto probada localmente y una copia recuperable del código.

Estas mejoras **aún no están publicadas** para el equipo.

## En qué estamos trabajando

El MyDesk oficial recibió actualizaciones recientes. El siguiente trabajo es unir esas mejoras con nuestra versión piloto y comprobar que todo siga funcionando. **La unión todavía no se ha realizado.**

## Jira: transición

Bruno no tiene acceso al respaldo de Jira. La migración y recuperación histórica quedan a cargo de una persona autorizada.

Para iniciar sin bloquear al equipo, las primeras tareas se registrarán manualmente. Jira se mantiene como referencia del histórico.

## Qué impide publicar

- Falta acceso autorizado para respaldar los datos actuales del MyDesk.
- Falta coordinar una publicación controlada con quien administra el servicio.
- Todavía debemos integrar las actualizaciones recientes del MyDesk oficial.

## Próximo hito

**Integrar la versión piloto → proteger los datos actuales → publicar de forma controlada → validar un equipo.**
